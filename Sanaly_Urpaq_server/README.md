# «Саналы ұрпақ» · тестовая версия

1. Распакуй архив. Создай приватный репозиторий GitHub и загрузи Dockerfile, bot.py и README.md в его корень.
2. В Railway создай проект из этого репозитория. Оставь один экземпляр сервиса. Публичный домен не нужен.
3. Подключи к сервису Volume с путём /data. В Variables задай BOT_TOKEN (действующий токен BotFather), OWNER_CODE и TESTER_CODE. Оба кода должны быть разными, случайными, по 20–64 символа из латинских букв, цифр, дефиса и подчёркивания. Храни значения только в настройках Railway.
4. Останови предыдущий скрипт PowerShell через Ctrl+C и разверни сервис. В логах должно появиться «бот запущен».
5. В личном чате со своего аккаунта отправь /start ВАШ_OWNER_CODE, подставив код владельца. Добавь бота в закрытую группу и со своего аккаунта отправь в неё /bindgroup@username_бота. Бот ответит «Тестовая группа подключена».
6. Со второго аккаунта отправь боту в личку /start ВАШ_TESTER_CODE, подставив код тестировщика. Выбери язык и отправь вымышленное обращение. Проверь, что в группе и в личном чате совпадает номер.

На подключённом диске сохраняются ID привязанных чатов и позиция очереди Telegram. Незаконченные формы хранятся в памяти. Для тестирования используй вымышленные данные.
